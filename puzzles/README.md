# Puzzle de la famille Lapin

## Description
Ce projet est un jeu de puzzle simple destiné aux enfants de 3 ans. Le but du jeu est de reconstituer une image de la famille de lapins en déplaçant des pièces de puzzle.

## Structure du projet
Le projet se compose des fichiers et dossiers suivants :

- **index.html** : Contient la structure de l'interface du jeu, y compris le titre, le canvas pour le puzzle, et les sections pour la sélection d'images et les instructions du jeu.
  
- **style.css** : Définit les styles pour le jeu, y compris la mise en page, les couleurs, les polices et les effets de survol pour les miniatures d'images.
  
- **script.js** : Contient la logique principale du jeu de puzzle. Inclut des fonctions pour charger les images, afficher l'écran de sélection, gérer les interactions de glisser-déposer et vérifier les conditions de victoire.
  
- **images/** : Dossier contenant les fichiers image pour les pièces de puzzle. Les images doivent être au format PNG ou JPG.
  
- **sounds/** : Dossier pouvant contenir des fichiers audio pour les interactions du jeu, tels que des sons de validation ou des sons de victoire.

## Instructions pour exécuter le jeu
1. Téléchargez ou clonez le dépôt sur votre machine.
2. Ouvrez le fichier `index.html` dans un navigateur moderne (Chrome, Firefox, Safari, Edge).
3. Choisissez une image de puzzle parmi les miniatures affichées.
4. Glissez les pièces pour reconstituer l'image.
5. Profitez du jeu !

## Bonus
Des fonctionnalités supplémentaires peuvent être ajoutées, telles que des sons de validation, une animation de confettis à la victoire, un chronomètre pour mesurer le temps de résolution, et la possibilité de sauvegarder le puzzle préféré de l'enfant dans le stockage local.

## Auteurs
Ce projet a été développé pour offrir une expérience ludique et éducative aux jeunes enfants.
